## 🛠 Feature Breakdown

### Feature 1 — Recon
Spot leak signs: unknown sessions, small unauthorized transfers, rate spikes.

### Feature 2 — Wallet Scan
Check private keys, seed phrases, and wallet permissions.

### Feature 3 — API Scan
Detect exposed cloud tokens, GitHub secrets, and env leaks.

### Feature 4 — Session Scan
Find stolen cookies, JWTs, and OAuth refresh tokens.

### Feature 5 — Revoke + Rotate
Safely revoke, rotate, and reissue every compromised credential.

### Feature 6 — Post-Leak Hardening
Lock down accounts, enable 2FA, and add monitoring.
